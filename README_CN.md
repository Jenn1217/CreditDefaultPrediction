# 基于 LightGBM 的信贷违约风险预测

本项目基于大规模借款人行为数据，构建 信贷违约风险预测模型，实现从 数据预处理、特征工程、模型训练到模型解释 的完整机器学习建模流程，并对多种模型进行性能比较。

项目使用 Python + LightGBM 构建违约预测模型，并通过 SHAP 解释框架分析关键风险特征，为信贷风控提供数据驱动的决策支持。

# ⭐ Project Highlights

大规模信贷数据建模：基于 Python（Pandas / Scikit-learn / LightGBM）对 百万级借款人行为数据进行建模分析，构建完整信贷违约预测流程。

# 项目背景

在互联网金融和信贷平台中，**违约风险预测（Credit Default Prediction）** 是核心风控问题之一。
通过机器学习方法分析借款人历史行为数据，可以有效识别高风险用户，从而降低金融机构的信贷风险。

本项目利用借款人历史行为数据，构建机器学习模型预测借款人是否违约，并分析影响违约的重要因素。

---

# 数据说明

数据包含 **百万级借款人行为记录**，主要包括以下信息：

* 借款人基本信息
* 借款金额与利率
* 信贷历史记录
* 历史还款行为
* 信贷账户信息
* 时间相关特征

目标变量：

```
isDefault
```

含义：

* 0：未违约
* 1：发生违约

# 方法流程

本项目采用标准机器学习建模流程。

## 1 数据预处理

主要包括：

* 数据读取
* 缺失值处理
* 时间特征转换
* 异常值处理

对关键时间字段进行处理，例如：

* `issueDate` → 借款时间
* `earliesCreditLine` → 信贷历史开始时间

并提取信用历史长度等特征。

---

## 2 特征工程

特征工程主要包括：

* 时间特征提取
* 类别变量编码
* 数值特征处理
* 特征筛选

使用 **Pandas 和 Scikit-learn** 完成数据处理与特征构建。

---

## 3 模型训练与对比

本项目训练并比较了多种机器学习模型：

| 模型                  | 说明       |
| ------------------- | -------- |
| Logistic Regression | 逻辑回归基线模型 |
| Random Forest       | 随机森林模型   |
| XGBoost             | 梯度提升树模型  |
| LightGBM            | 高效梯度提升框架 |

模型评价指标采用：

```
AUC (Area Under ROC Curve)
```

用于衡量模型对违约用户的识别能力。

---

## 4 模型结果

模型对比结果表明：

| 模型                  | 表现                 |
| ------------------- | ------------------ |
| Logistic Regression | 基线模型               |
| Random Forest       | 性能提升               |
| XGBoost             | 较好表现               |
| **LightGBM**        | **AUC = 0.86（最佳）** |

LightGBM 在违约预测任务中表现最优。

# 模型解释

为了提高模型的可解释性，本项目引入 **SHAP（Shapley Additive Explanations）** 进行模型解释。

SHAP 可以：

* 识别影响违约概率的关键特征
* 分析不同特征对预测结果的贡献
* 提供模型决策的可解释性

这对于金融风控模型具有重要意义。
